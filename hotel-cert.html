Hotelbeds Hotels (Hotel API) — certificación

Página técnica para demo con Hotelbeds mañana. Usa el proxy POST /api/hotelbeds-availability (disponibilidad, checkrates, booking) y GET ?status=1 / ?diagnostic=1. Mismas variables que el resto del sitio: API_Key / HOTELBEDS_API_KEY y secret. Entorno test/prod según HOTELBEDS_ENV.

0. Conectividad

1. Disponibilidad (POST sin action)

El proxy arma el body hacia /hotel-api/1.0/hotels. Por defecto destino BRG si no indicas nada. Importante: el destino en Hotel API es 1 a 3 caracteres (no uses BUR2 — devuelve 400).

Respuesta

Pulsa «Buscar disponibilidad» o conectividad.

Tarifas — elegir rateKey

Selecciona una tarifa; se rellena el campo inferior. Si el tipo es RECHECK, usa CheckRate antes del booking (botón en §2).

Hoteles / tarifas

2. CheckRate (action: checkrates)

Obligatorio cuando la tarifa viene como RECHECK. Máx. 10 rateKey por petición (aquí una).

3. Booking (action: booking)

Una habitación / un adulto titular (como en paquetes). Incluye tolerance: "2". Opcional: JSON completo abajo sustituye el formulario.
